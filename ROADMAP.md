# Roadmap

What's planned. No dates; things ship when they work.

## Now

- Physics crash fix: keep confirming it in real races. Its first real catch was in November 2026: 2 crash values in
  one online session, with no crash.

## Next

- Automatic updates: get new versions without downloading them by hand.
- Crash report sharing (opt-in): send a crash report in one step so new crash types can be found and fixed. Off
  unless you turn it on.
- More crash fixes: the four fixed so far cover about 65% of reported crashes. Next are the smaller ones, like
  crashes when leaving a session.
