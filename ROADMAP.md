# Roadmap

What's planned. No dates; things ship when they work.

## Now

- Physics crash fix: keep confirming it in real races. Its first real catch was in November 2026: 2 crash values in
  one online session, with no crash.
- Crash reports: see what new crash types show up now that reports can be sent.

## Next

- More crash fixes: the four fixed so far cover about 65% of reported crashes. Next are the ones crash reports show
  matter most, like crashes when leaving a session.

## Looking into

- Getting stuck on "syncing" when rejoining a server after a crash.
- Why rider positions sometimes go bad (the cause behind the physics crash).

## Help

Crashed with mxbfix installed? If you left crash reports on, it reaches us by itself. If you turned them off, you can
[open an issue](../../issues/new/choose) and tell us what you were doing. Please don't attach the report file: it
includes details like your server name that shouldn't be public.
